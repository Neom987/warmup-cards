# 升温 · A Game For Two

一个给两个人的抽卡小游戏。抽一张，两个人在同一台手机上各自选一次——做 / 轻一点 / 不做——然后一起揭晓。

**这是一个单文件网页应用**：`index.html` 双击就能玩，不联网、不上传任何数据，所有进度只存在浏览器 localStorage 里。

> 18+ · 请在双方都同意、且随时可以说停的前提下使用。游戏里第一条就是「任何一方说停就停，不需要理由，也不追问」。

设计与迭代记录见 [`PROJECT.md`](PROJECT.md)。

---

## 怎么玩

1. 打开 `index.html`
2. 勾选「我们已经商量过」，设置温度上限（调情 / 升温 / 深处）和这一局抽几张
3. 轻触或上滑翻牌，然后**两个人都要各自选一次**：
   - 你先选（做 / 轻一点 / 不做），屏幕不会显示你选了什么，只留一句「把手机给 TA」
   - 手机递过去，TA 再选一次
   - 一起揭晓：都选「做」就做；有一人选「不做」这张就放下，而且不显示是谁选的
4. 每 10 张自动升一档；也可以随时按「升一档」自己往上走，或「降一档」退回上一档
5. 中途会插进来「规则卡」，改这一局的规则（停一下 / 不说话 / 说一件 / 挑一张 / 闭上眼），可以在开局关掉

## 各自选

这个游戏里，一张牌要不要做，**不是一个人能决定的事**。

两个人轮流在同一台手机上回答同一个问题（这张，你 OK 吗），答案在最后一起亮出来：

| 两个人的答案 | 结果 |
|---|---|
| 都「做」 | 做 |
| 都「轻一点」 | 按卡面的「退路」那条来 |
| 都「不做」 | 这张放下，算一次「合拍」 |
| 一个「做」一个「轻一点」 | 取更轻的那个 |
| 任何一个人「不做」 | 这张放下，**不显示是谁选的** |

三条不会变的规矩：

- **一票就够。** 一个人说「不做」，这张就不做，不需要理由，也不需要对方同意。
- **不点名。** 只有一个人说了「不做」时，答案栏整个隐藏，只留一句「先放下 · 谁选的不说，也不用解释」。
- **「不做」不花任何额度。** 没有次数限制，也不扣分。原来那 3 次跳过配额已经删掉了——「你只有三次拒绝」本身就是一句坏消息。

## 卡片库

543 张：500 张基础卡（L1 120 / L2 156 / L3 224）+ 43 张道具卡。

| 档位 | 定位 | 主要类别 |
|---|---|---|
| 第一幕 · 调情 | 接吻、抚摸、开始脱 | 触碰 72 / 指令 20 / 语言 8 / 眼神 8 / 场景 8 / 真心话 4 |
| 第二幕 · 升温 | 口、手、边缘 | 触碰 95 / 指令 26 / 场景 12 / 语言 11 / 眼神 7 / 真心话 5 |
| 第三幕 · 深处 | 进入、节奏、掌控 | 触碰 157 / 指令 30 / 场景 13 / 眼神 11 / 语言 7 / 真心话 6 |

- 六类视角轮换：语言撩拨 / 距离眼神 / 触碰引导 / 场景氛围 / 真心话 / 指令掌控
- 每张卡有唯一标题与正文，同档近似度 ≥ 0.86、跨档 ≥ 0.72 会被校验脚本拦下
- 高尺度卡带「退路」（`alt`），给一个更轻的替代玩法

## 规则卡

不在牌库里，是中途插进来的一张，**改的是这一局的规则而不是内容**。每 7 张普通卡插一张，可在开局关掉。

| 规则卡 | 改什么 |
|---|---|
| 停一下 | 抱住 60 秒，什么都不做，自动计时 |
| 不说话 | 接下来两张只能用动作和眼神（说「停」不算破例） |
| 说一件 | 各说一件今天没来得及说的小事，对方只听不接话 |
| 挑一张 | 下一张从三张里挑，另外两张之后照常出现 |
| 闭上眼 | 下一张闭着眼做 |

五种全部是「降级或增权」，没有一种是加码——这类游戏真正缺的不是强度，是控制感和呼吸。边界清单里「遮挡」划了「不要」，「闭上眼」就不会出现。

## 道具

11 种：丝巾、镜子、蜡烛、冰块、羽毛、按摩油、发圈、骰子、耳机、口红、震动棒。

- 没勾的道具，相关卡片不会进牌堆
- **道具节奏**：每 4 张普通卡必插一张道具卡，道具是关卡而不是彩蛋
- **主道具**：每局随机指定一件，它的卡优先出现
- 组合卡需要两件道具同时启用（例如 震动棒 + 丝巾）

## 边界清单

6 条三态（可以 / 看情况 / 不要）：触碰、亲吻、遮挡、留痕、节奏、命令。
选「不要」会真的把这些卡过滤掉，不是摆设。

## 开发

```bash
python build.py              # src/cards/*.json + src/app.html → index.html（单文件）
python check_cards.py        # 卡片校验：唯一性/字数/类别覆盖/近似重复/红线词/道具引用
python tools/audit_content.py  # 内容体检：跨档近似、词频、长度分布、缺主语
python tools/apply_theme.py    # 改完 src/theme.css 后重新内联进模板
python tools/make_font.py      # 卡片新增生僻字后重建字体子集（首次会自动下载 TTF）
python tools/import_500.py     # 从 data/cards-500-2026-10-29.md 重新导入基础卡
python tools/export_all_cards.py  # 导出全部卡片为一份 Markdown，交给外部 AI 改写
```

**目录**

```
index.html          构建产物，双击即玩，同时是 Pages 入口
build.py            JSON → 单文件
check_cards.py      卡片校验
src/app.html        应用模板（/*__DATA__*/ 数据占位、/*__VENDOR__*/ 库占位）
src/theme.css       界面主题
src/vendor/         chroma.min.js（颜色）+ anime.min.js（动效），构建时内联
src/font.css        字体子集（base64 woff2，由 tools/make_font.py 生成）
src/cards/          tier1..3.json 三档卡片 / props.json 道具
data/               500 张卡片的原始 Markdown 稿（import_500.py 的输入）
tools/              构建链、内容审计、回归脚本
```

**第三方库**

只有两个，都在 `src/vendor/`，`build.py` 会把它们内联进 `index.html`，所以产物仍然是**零网络请求**的单文件。

- **chroma.js** 2.4.2（BSD-3）——房间换色走 LCH 而不是 sRGB，否则玫瑰到薄荷的中途会经过一段灰；每张卡的第二凝胶色、类别标签的字色也由它算。
- **anime.js** 3.2.2（MIT）——翻牌的编排：卡转、内容分层浮起、光晕冲击、结束页数字滚动。

**字体**

正文字体是霞鹜文楷（LXGW WenKai，SIL OFL 1.1）。整套中文 19 MB，这里按「本应用实际用到的 892 个字」做子集化，压到 322 KB woff2 后 base64 内联，所以离线双击打开也是同一个字体；用户自己输入的名字等字符会自动回退到系统字体。

**回归**

`tools/flow.js`（26 项断言：翻牌 / 各自选 / 传递 / 揭晓 / 不点名 / 撤销 / 升档 / 续局）、`ui2.js`（折叠/亮度/字号/计时）、`maxtier.js`（单档上限）、`overflow.js`（最大字号溢出）、`fit.js`（三种小屏）、`prop_flow.js`（道具节奏与主道具）、`randomness.js`（跨局重合度）。基于 puppeteer-core + 本机 Edge。
