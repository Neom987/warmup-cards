# 升温 · A Game For Two

一个给两个人的抽卡小游戏。抽一张，照着做；跳过有次数，降档不算数。

**这是一个单文件网页应用**：`index.html` 双击就能玩，不联网、不上传任何数据，所有进度只存在浏览器 localStorage 里。

> 18+ · 请在双方都同意、且随时可以说停的前提下使用。游戏里第一条就是「任何一方说停就停，不需要理由，也不追问」。

---

## 怎么玩

1. 打开 `index.html`
2. 勾选「我们已经商量过」，设置温度上限（调情 / 升温 / 深处）和这一局抽几张
3. 轻触或上滑翻牌 → 右滑「做完了」→ 左滑「跳过」（每局 3 次，可撤销）
4. 每 10 张自动升一档；也可以随时按「升一档」自己往上走，或「降一档」退回上一档（不消耗跳过次数）

## 卡片库

403 张，三档各 120 张 + 43 张道具卡。

| 档位 | 定位 | 主要类别 |
|---|---|---|
| 第一幕 · 调情 | 接吻、抚摸、开始脱 | 语言 36 / 触碰 26 / 眼神 21 / 场景 16 / 真心话 14 / 指令 7 |
| 第二幕 · 升温 | 口、手指、节奏 | 触碰 55 / 指令 18 / 场景 15 / 眼神 13 / 真心话 10 / 语言 9 |
| 第三幕 · 深处 | 束缚、边缘、掌控 | 触碰 41 / 指令 34 / 场景 17 / 语言 12 / 真心话 9 / 眼神 7 |

- 六类视角轮换：语言撩拨 / 距离眼神 / 触碰引导 / 场景氛围 / 真心话 / 指令掌控
- 每张卡有唯一标题与正文，同档近似度 ≥ 0.86、跨档 ≥ 0.72 会被校验脚本拦下
- 高尺度卡带「退路」（`alt`），给一个更轻的替代玩法

## 道具

11 种：丝巾、镜子、蜡烛、冰块、羽毛、按摩油、发圈、骰子、耳机、口红、震动棒。

- 没勾的道具，相关卡片不会进牌堆
- **道具节奏**：每 4 张普通卡必插一张道具卡，道具是关卡而不是彩蛋
- **主道具**：每局随机指定一件，它的卡优先出现
- 组合卡需要两件道具同时启用（例如 震动棒 + 丝巾）

## 边界清单

6 条三态（可以 / 看情况 / 不要）：触碰、亲吻、遮挡、留痕、节奏、命令。
选「不要」会真的把这些卡过滤掉，不是摆设。

## 开发

```bash
python build.py            # 把 src/cards/*.json 内联进 src/app.html → index.html
python check_cards.py      # 卡片校验：唯一性/字数/类别覆盖/近似重复/红线词/道具引用
python tools/apply_theme.py  # 把 src/theme.css + src/font.css 内联进 <style>
python tools/audit_content.py # 内容体检：跨档近似、词频、长度分布、缺主语
```

**目录**

```
src/app.html        应用模板（/*__DATA__*/ 是数据占位）
src/theme.css       界面主题
src/font.css        字体子集（base64 woff2，由 tools/make_font.py 生成）
src/cards/          tier1..3.json 三档卡片 / props.json 道具
tools/              构建、校验、改写、回归脚本
```

**字体**

正文字体是霞鹜文楷（LXGW WenKai，SIL OFL 1.1）。整套中文 19 MB，这里按「本应用实际用到的 892 个字」做子集化，压到 322 KB woff2 后 base64 内联，所以离线双击打开也是同一个字体；用户自己输入的名字等字符会自动回退到系统字体。

**回归**

`tools/flow.js`（13 步交互）、`ui2.js`（折叠/亮度/字号/计时）、`maxtier.js`（单档上限）、`overflow.js`（最大字号溢出）、`fit.js`（三种小屏）、`prop_flow.js`（道具节奏与主道具）、`randomness.js`（跨局重合度）。基于 puppeteer-core + 本机 Edge。
