# 升温 · A Game For Two

一个给两个人的抽卡小游戏。开局先定好这一晚的规则（模式、上限、张数），然后一张接一张：翻牌，照做，或者跳过。

**这是一个单文件网页应用**：`index.html` 双击就能玩，不联网、不上传任何数据，所有进度只存在浏览器 localStorage 里。

> 18+ · 请在双方都同意、且随时可以说停的前提下使用。游戏里第一条就是「任何一方说停就停，不需要理由，也不追问」。

设计与迭代记录见 [`PROJECT.md`](PROJECT.md)。

---

## 怎么玩

1. 打开 `index.html`
2. 填两个人的称呼，选玩法、温度上限（调情 / 升温 / 深处）、这一局抽几张（10 / 20 / 30 / 抽到停）
3. 勾选「我们已经商量过」，开始
4. 轻触或上滑翻牌，然后按一个动作：

| 动作 | 做什么 |
|---|---|
| 做完了 | 记一次完成，下一张 |
| 跳过 | 换一张，不记完成；每局只有 **3 次** |
| 升一档 | 立刻往上走一档，不消耗跳过次数 |
| 降一档 | 立刻退回上一档，换同类别更轻的一张；**不限次数，也不算跳过** |

5. 每 10 张自动升一档（限时模式每 5 张），到了上限就一直停在那里
6. 想停就停：右上角长按暂停，或结束这一局；结束页会列出这一局抽到的和收藏的

## 六种玩法

同一副牌，六种抽法。开局选一次，整局不变。

| 模式 | 抽法 |
|---|---|
| 经典 | 一张接一张，每局随机一方主导 |
| 轮流 | 抽卡的人轮换，「做」的人跟着换，不会总是同一个人在服务 |
| 三选一 | 每次摆三张背面牌，只看得见类别和档位，选一张，其余放回牌堆 |
| 掷骰 | 每抽一张先掷骰子：语言 / 眼神 / 触碰 / 场景 / 真心话 / 指令，骰到什么类别就抽什么 |
| 限时 | 5 / 10 / 15 分钟倒计时，时间内尽量多抽；时间到做完手上这张就收尾 |
| 言语局 | 只抽语言、眼神、真心话三类，偏重说和看，适合热身或不想太直接的晚上 |

## 卡片库

615 张：558 张基础卡（L1 145 / L2 179 / L3 234）+ 57 张道具卡。

| 档位 | 定位 | 主要类别 |
|---|---|---|
| 第一幕 · 调情 | 接吻、抚摸、开始脱 | 触碰 81 / 指令 23 / 场景 12 / 语言 11 / 眼神 10 / 真心话 8 |
| 第二幕 · 升温 | 口、手、边缘 | 触碰 104 / 指令 28 / 场景 15 / 语言 14 / 眼神 9 / 真心话 9 |
| 第三幕 · 深处 | 进入、节奏、掌控 | 触碰 157 / 指令 32 / 场景 16 / 眼神 12 / 真心话 9 / 语言 8 |

- 六类视角轮换：语言撩拨 / 距离眼神 / 触碰引导 / 场景氛围 / 真心话 / 指令掌控
- 每张卡有唯一标题与正文，同档近似度 ≥ 0.86、跨档 ≥ 0.72 会被校验脚本拦下
- 高尺度卡带「退路」（`alt`），给一个更轻的替代玩法
- 抽过的卡不会在同一个浏览器里重复出现，直到你「清空已抽记录」

## 道具

11 种：丝巾、镜子、蜡烛、冰块、羽毛、按摩油、发圈、骰子、耳机、口红、震动棒。

- 没勾的道具，相关卡片不会进牌堆
- **道具节奏**：每 4 张普通卡之后必插一张道具卡，道具是关卡而不是彩蛋
- **主道具**：每局随机指定一件，它的卡优先出现
- 组合卡需要两件道具同时启用（例如 震动棒 + 丝巾）

## 边界清单

6 条三态（可以 / 看情况 / 不要）：触碰、亲吻、遮挡、留痕、节奏、命令。
选「不要」会真的把这些卡过滤掉，不是摆设。

## 开发

```bash
python build.py                # src/cards/*.json + src/app.html → index.html（单文件）
python check_cards.py          # 卡片校验：唯一性/字数/类别覆盖/近似重复/红线词/道具引用
node tools/flow.js             # 主流程回归（jsdom，不需要浏览器）
python tools/audit_content.py  # 内容体检：跨档近似、词频、长度分布、缺主语
python tools/apply_theme.py    # 改完 src/theme.css 后重新内联进模板
python tools/make_font.py      # 卡片新增生僻字后重建字体子集（首次会自动下载 TTF）
python tools/import_500.py     # 从 data/cards-500-2026-10-29.md 重新导入基础卡
python tools/export_all_cards.py  # 导出全部卡片为一份 Markdown，交给外部 AI 改写
```

**源与产物：`src/` 是唯一的源。** `index.html` 只由 `build.py` 生成，手改会在下一次构建时被覆盖。
如果只是想快速试一版界面，改 `index.html` 试完记得反哺回 `src/app.html` / `src/theme.css`。

**目录**

```
index.html          构建产物，双击即玩，同时是 Pages 入口
build.py            JSON → 单文件
check_cards.py      卡片校验
src/app.html        应用模板（/*__DATA__*/ 数据占位）
src/theme.css       界面主题（v5 凝胶灯：换一张卡，房间换一个颜色）
src/font.css        字体子集（base64 woff2，由 tools/make_font.py 生成）
src/cards/          tier1..3.json 三档卡片 / props.json 道具与道具引用
data/               500 张卡片的原始 Markdown 稿（import_500.py 的输入）
tools/              构建链、内容审计、回归脚本
```

**字体**

正文字体是霞鹜文楷（LXGW WenKai，SIL OFL 1.1）。整套中文 19 MB，这里按「本应用实际用到的字」做子集化，
压到 322 KB woff2 后 base64 内联，所以离线双击打开也是同一个字体；用户自己输入的名字等字符会自动回退到系统字体。

**第三方库**

没有。v5 时代内联过 chroma.js（LCH 换色）与 anime.js（翻牌编排），现在这两件事都由
`src/app.html` 里几十行原生 JS 和 CSS 完成：类别色 → 亮度判字色 + 色相 +28° 得第二色，
换色靠 `background-color` 过渡，翻牌靠 `transform`，内容分层浮起靠 keyframes 的 delay。
产物仍是**零网络请求**的单文件（620 KB）。

**回归**

- `tools/flow.js` —— 主流程，跑在 jsdom 里，不需要浏览器（`npm i` 之后 `node tools/flow.js`）。
  30 条断言：设置页 / 六种玩法各自能开局 / 翻牌 / 做完 / 跳过 / 升降档 / 撤销 / 收藏 / 暂停继续 / 全程无未捕获异常。
- `tools/ui2.js`、`maxtier.js`、`overflow.js`、`fit.js`、`prop_flow.js`、`randomness.js` —— 需要真浏览器
  （puppeteer-core + 本机 Edge，脚本顶部有 `EDGE` 常量），分别管折叠/亮度/字号/计时、单档上限、
  最大字号溢出、三种小屏、道具节奏、跨局重合度。
